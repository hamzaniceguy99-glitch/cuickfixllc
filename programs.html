Program 02 · When it is actually the battery

Battery replacement

A phone dying at thirty per cent is usually a battery, but not always — a background fault can drain one just as fast. We test before replacing, and if the battery has swollen we will tell you to stop using the device immediately, because that is a genuine hazard.

Program 03 · No promises, ever

Liquid damage

Liquid damage is corrosion, and corrosion keeps going. A clean can rescue a device, and the same device can fail two months later for the same reason. Anyone promising a guaranteed fix on water damage is not being straight with you. Rice does nothing — bring it in powered off.

  • 1 to 3 days
  • Any device
  • Assessment fee quoted
  • Powered off, not charged

Program 04 · Attempted, not guaranteed

Computers & data recovery

Data recovery is an attempt, never a promise. A drive with mechanical failure may need a specialist lab, and we will tell you when it is beyond us rather than making it worse by trying. If the data matters, stop using the machine now — continuing to run it often destroys what is still recoverable.

  • 1 to 5 days
  • Laptops and desktops
  • Quoted after diagnosis
  • Stop using the device
